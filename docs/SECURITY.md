# Security Model

Agent Fabric assumes model output, user input, retrieved content, remote tool output, and external agent output can all be malicious or wrong.

## Non-negotiable boundaries

1. **Models do not own authorization.** PHP policies/tools/connectors/workflows decide what may execute.
2. **Tenant scope is enforced in storage/query code**, never by a prompt instruction alone.
3. **Live sensitive state is accessed through explicit tools/connectors**, not copied into training data.
4. **Write/financial/destructive operations require explicit governed code paths.**
5. **Ambiguous irreversible operations are not blindly retried.** They require reconciliation.
6. **Simulation/replay cannot execute governed command or remote-operation tools.**
7. **Model routing must respect classification, region, privacy, and retention policy before quality scoring.**

## Prompt injection

Prompt injection is not solved by string filtering. Agent Fabric uses trust-labelled context plus least-agency tools, PHP-side authorization, allowlisted connector fields/resources, approval gates, and evidence verification.

Retrieved/web/MCP/A2A content must be treated as untrusted data. `PromptBoundary` makes this explicit in serialized context.

## Connectors

Do not build connectors that execute arbitrary SQL or shell commands generated by the model. The built-in Eloquent connector is read-only and requires configured resources/fields. Writes belong in explicit tools/workflows.

## Delegated identity

Remote calls should use the smallest possible delegated scope. Do not give the agent a global service credential when it should inherit user/tenant permissions. `ActorIdentity`, `AuthorizationScope`, and `DelegatedCredential` are the core primitives for adapters.

## MCP/A2A

MCP and A2A adapters must authenticate remote endpoints, validate schemas, restrict outbound destinations, and avoid forwarding secrets or tenant data outside policy. Treat discovered tool descriptions and remote responses as untrusted.

## SSRF

Any tool/connector accepting URLs should apply `UrlSafetyGuard` or a stricter environment-specific network policy. Block localhost, metadata endpoints, private networks, unsafe schemes, and DNS rebinding at the network layer as well.

## Audit / traces

Do not store secrets, raw credentials, OTPs, authorization headers, or unnecessary PII in prompts, traces, audit logs, or tool results. `SecretRedactor` is a baseline utility, not a substitute for a data-minimization policy.

## Replay / shadow

Replay and shadow mode default to no side effects. A plugin must never silently bypass that boundary.

## Compensation

Workflow compensation is best-effort and is **not** a distributed transaction. A compensation handler cannot guarantee reversal of an external financial/payment action. Use reconciliation/invariant systems for unresolved outcomes.
